# Charged after cancelling

You cancelled something, and a personal credit card in the United States is still being charged. Add the cancellation email, your statements, and what the card app shows. The page matches each charge to the statement that first showed it, counts the 60 days a written notice has to arrive at your card company, and drafts that notice for you to check.

You send it yourself, if you decide to. The page does not send anything, file anything, or contact your card company or the business. It does not decide whether the cancellation took effect, and it does not promise a refund.

Debit cards, bank accounts, business cards, prepaid cards, and cards issued outside the United States are not given this procedure. The page says so and points you to your bank or card company.

The federal rule is 12 CFR 1026.13 (Regulation Z), read on 16 November 2026, along with the public billing-rights text of three large card companies on that date. Your own statement decides the address, and whether a message in the app or on the website counts as the written notice.

Nothing you type is uploaded. There is no account. To keep the work, save the file the page offers and store it on your device. Delete that file to delete the case. Open the saved file again later and the page recounts the days from that day.

## What this page does not do

It prepares. It does not act. A saved file is not a notice anyone has received, and a drafted letter is not a result.

## This repository

This repository is the published site: the files GitHub Pages serves, as built. Everything runs in the browser from these files. To try it locally, serve this directory over HTTP (`python3 -m http.server 8000`) and open http://localhost:8000/. The test suite and build scripts are kept with the source and aren't part of this repository.
